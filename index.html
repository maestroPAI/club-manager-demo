🤖 Built-in AI attendance agent

Games under capacity fill themselves back up - automatically.

The agent watches every upcoming game. When one drops below a fill threshold you set, it ranks the regulars most likely to show up - by past attendance and subscription status - and drafts a ready-to-send message. An admin approves with one click; nothing goes out on its own. See it live in Admin Area → Run the agent - there's a real pending proposal waiting for approval right now.
